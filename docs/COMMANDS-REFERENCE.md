# Impeccable 命令与技能说明

本文档列出 Impeccable 中所有**可用的斜杠命令**与**设计技能**，以及使用方式。

---

## 一、斜杠命令（17 个）

在 Cursor、Claude Code、Gemini CLI、Codex CLI 等工具中安装 Impeccable 后，在 AI 聊天中输入 `/` 即可看到以下命令并调用。

| 命令 | 说明 |
|------|------|
| `/teach-impeccable` | 一次性设置：收集项目设计上下文并写入 AI 配置文件，建立持久设计规范。建议在新项目或新仓库中先执行一次。 |
| `/audit` | 对界面做全面质量审计（可访问性、性能、主题、响应式等），生成问题清单与建议报告，不直接改代码。 |
| `/critique` | 从 UX 角度评审设计：视觉层次、信息架构、情感共鸣、整体质量，并给出可执行反馈。 |
| `/normalize` | 按设计系统做规范化，保证与现有设计规范和组件用法一致。 |
| `/polish` | 上线前最后一轮打磨：对齐、间距、一致性、细节，让成品更精致。 |
| `/distill` | 做减法，去掉多余复杂度，保留核心体验与信息。 |
| `/clarify` | 改进不清晰的 UX 文案、错误提示、微文案、标签与说明，让界面更易理解。 |
| `/optimize` | 提升界面性能：加载速度、渲染、动效、图片与资源、打包体积等。 |
| `/harden` | 增强健壮性：错误处理、国际化(i18n)、文案溢出与边界情况。 |
| `/animate` | 为功能增加有目的的动效与微交互，提升可用性与愉悦感。 |
| `/colorize` | 为过于单调的界面增加有策略的颜色，提升表现力。 |
| `/bolder` | 让偏保守或无聊的设计更鲜明、有冲击力，同时保持可用性。 |
| `/quieter` | 让过于强烈或抢眼的设计更克制，保持品质与重点。 |
| `/delight` | 增加小惊喜、个性与记忆点，让界面从「好用」到「好用又讨喜」。 |
| `/extract` | 从现有界面中抽成可复用组件、设计 token 与模式，沉淀到设计系统。 |
| `/adapt` | 适配不同屏幕尺寸、设备与使用场景（如移动端、平板、桌面、打印等）。 |
| `/onboard` | 设计或改进引导流程、空状态与首次使用体验，帮助用户快速理解价值。 |

### 命令参数（可选）

多数命令支持在命令后追加「范围」或「区域」，用于限定要处理的文件或功能，例如：

- `/audit header` — 只审计与 header 相关的部分
- `/polish checkout-form` — 只打磨结账表单
- `/normalize settings-page` — 只规范化设置页

具体是否支持以及传参方式因平台而异（如 Cursor 对参数支持有限，可在命令后直接输入要针对的区域或文件名）。

## 二、设计技能（非斜杠命令）

以下技能**没有对应的斜杠命令**，由 AI 在完成前端/设计相关任务时自动引用，或在你描述需求时作为设计依据。

| 技能名称 | 说明 |
|----------|------|
| **frontend-design** | 主设计技能：创建有辨识度、可上线的前端界面。包含排版、色彩与对比、空间布局、动效、交互、响应式、UX 文案等参考文件，以及 DO / DON'T 反模式，供其他命令和对话使用。 |

---

## 三、使用前提

- **Cursor**：需使用 Nightly 渠道，并在设置中启用 Agent Skills。详见 [docs/CURSOR.md](CURSOR.md)。
- **Claude Code / Gemini CLI / Codex CLI**：按各工具文档完成安装与配置后即可使用上述命令。

---

## 四、安装与获取

- 官网下载（按平台选 Cursor / Claude Code / Gemini / Codex）：[impeccable.style](https://impeccable.style)
- 从本仓库复制 Cursor 用内容（需先执行 `bun run build`）：
  ```bash
  cp -r dist/cursor/.cursor /path/to/your-project/
  ```
